Crop & edit-robust matching

Content Registry

The Authenticity Fingerprint on the main page proves “is this the exact same file” and “does this still look the same after recompression.” Neither one survives a crop — the perceptual hash there is a description of the whole frame, and cropping it breaks the comparison almost immediately. This page answers a different, harder question: is this a crop, edit, or partial reuse of something already registered? That's the actual mechanism behind stopping someone from cropping a signature off a registered artwork and reselling it as new.

Registering stores only a signed fingerprint record and a content-similarity vector — never the image itself, the same “nothing you upload is stored” promise as the rest of this app.
